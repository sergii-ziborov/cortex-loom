# Cortex fine-tune corpus

Generated by `cargo run -p cortex-eval -- corpus`.

These records are **Cortex-original**: eval gold, generated extraction rows, typed sequence packets, and mechanism labels. Superpowers is a token/quality baseline we measure against. We rewrote the workflows as typed graphs; we do **not** train on upstream `SKILL.md` bodies and we do not fork Superpowers.

## Files

- `sft.jsonl` — every record, train and holdout.
- `micro-extract-train.jsonl` — the only file a `micro_extract` fine-tune may consume: `targetRole=micro_extract` and `split=train`.
- `manifest.json` — counts by task, role, and split.

## Splits

`split=holdout` marks records derived from gold a gate is scored on (`fixtures/*.json`). Training on those and then claiming the gate would measure memorisation. `split=train` marks everything else: the generated micro-extraction rows (`src/micro_train.rs`), sequence step packets, and mechanism labels.

Split by `targetRole` when fine-tuning:

- `classification` → Qwen3-8B NPU classifier (and its extraction gate)
- `micro_extract` → Qwen3-0.6B extractor candidate
- `digest` → `qwen3.5:9b` citation-preserving digest / step packets

`trainingSource` is always `cortex-original`. `license` is MIT OR Apache-2.0.
